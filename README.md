One word an agent blurts out when it has no idea what to do: **recalculating** — the classic machine stall phrase, straight out of a lost GPS, said by an agent caught mid-task with nowhere to go.

## Run it

```sh
python3 main.py
```

This writes the entry word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it to stdout.
